Fundamentos de Desarrollo Backend con Java
Vianyi SHeccid Cárdenas Pérez
Centro Nacional de Innovación y Tecnología Francisco “El Chele” Moreno

Este programa registra el ingreso de motos, carros y camiones, cobrando una tarifa específica con cada uno de ellos, imprime una factura de acuerdo al precio de la tarifa por estacionamiento dependiendo del tiempo que estuvo parqueado el vehículo, por último al salir realiza un contro de todos los vehículos que estuvieron estacionados.
